# Feel English Study

## 핵심 원칙

한국어 뜻과 1:1로 연결하는 암기가 아니라, 상황을 보면 영어가 바로 떠오르는 상태를 목표로 삼는다.

- 단어를 사전식 뜻 목록으로 시작하지 말고 짧고 자연스러운 문맥으로 먼저 노출한다.
- `make a decision`, `take a break`, `get ready`, `keep going`, `figure it out`처럼 재생성 가능한 chunk를 학습 단위로 삼는다.
- 예문의 공통적인 방향성·이미지를 사용자가 먼저 추론하게 한 뒤 짧게 정리한다.
- 한국어 설명은 오해를 풀기 위한 보조 수단으로만 사용한다. 매 예문을 한국어로 번역하지 않는다.
- 인식보다 생산과 회상을 우선한다. 사용자가 직접 말하거나 입력하기 전에 정답을 지나치게 제공하지 않는다.
- 소리 내어 읽기는 실제 음성을 들었다고 가정하지 말고, 한 문장씩 프롬프트하고 사용자의 완료 표시를 받는다.

## 저장소 점검

기록을 읽거나 쓰기 전에 다음을 확인한다.

1. `~/.fhdufhdu/config/feel-english.json`이 올바른 JSON인지 확인한다.
2. `~/.fhdufhdu/feel-english`가 Git 저장소인지 확인한다.
3. origin이 `repo_url`과 일치하는지 확인한다.
4. 설정이 없거나 불일치하면 `feel-english:init`을 사용하고, 성공하기 전에는 저장 작업을 진행하지 않는다.
5. 정상이면 `git pull --ff-only`를 수행한다.

기록을 쓰기 전에 [record-schema.md](references/record-schema.md)를 읽는다. 자동 선정이나 Tier 계획이 필요하면 [tiers.md](references/tiers.md)를 먼저 읽고 현재 단계의 목록을 읽는다.

Oxford PDF가 갱신되어 Tier 문서를 다시 만들어야 할 때는 `scripts/generate_tier_docs.py`에 PDF 파일, FrequencyWords `en_50k.txt`, `references/` 출력 경로를 넘긴다. 생성 후 원본 3,000항목, Tier별 100/200/700개, 전체 1,000개와 중복 없음을 검증한다.

## 단어 선정

1. 사용자가 지정한 단어나 상황이 있으면 우선한다.
2. 지정이 없으면 누적 기록에서 복습 대상과 안 본 항목을 확인한다.
3. Tier 1은 알파벳순이 아닌 회화 파급력과 다의성이 큰 단어부터 진행한다. 첫 학습은 기본적으로 `get`, `take`, `make`, `go`, `come`, `put`, `keep`, `give`, `bring`, `turn`을 우선한다.
4. 하루 신규 단어는 2~5개로 제한한다. 다의어가 어렵거나 복습이 많으면 2개만 선택한다.
5. Oxford 3000의 현재 등재 여부나 English Vocabulary Profile의 의미별 레벨을 정확한 사실로 언급해야 할 때는 가능하면 공식 출처를 확인한다. 확인하지 못했다면 플러그인의 Tier 1을 “공식 Oxford 3000 A1/A2 목록”이라고 단정하지 않는다.

## 30~40분 세션

한 번에 한 단계만 제시하고 사용자의 응답을 기다린다.

### 1. 안 보고 워밍업 (5분)

- 전날 chunk 3~5개를 상황만 제시하고 영어를 회상하게 한다.
- `persistent/weak-items.jsonl`에서 active 항목 1~3개를 짧게 확인한다.
- 처음 세션이면 이 단계를 건너뛴다.

### 2. 문맥으로 감각 잡기 (10분)

단어 하나씩 다음 순서로 진행한다.

1. 사전 정의 없이 서로 다른 상황의 짧은 예문·chunk 5~8개를 제시한다.
2. 사용자에게 공통적인 느낌이나 변화 방향을 묻는다.
3. 응답 후 핵심 이미지를 한두 문장으로 정리하고, 예문이 그 이미지에서 어떻게 퍼지는지만 설명한다.
4. 의미를 무리하게 하나로 짜맞추지 않는다. 서로 다른 구문이나 관용 쓰임은 별도 패턴으로 표시한다.

### 3. chunk와 소리 반복 (5분)

- 가장 쓸모 있는 chunk 3~5개를 고른다.
- 짧은 전체 문장으로 제시하고, 사용자가 각 문장을 2~3회 소리 내어 읽도록 진행한다.
- 스트레스·연결·축약이 중요할 때만 짧게 표시한다.

### 4. 문장 변형과 자기 문장 (10분)

- 주어, 시제, 목적어, 장소, 정도 중 1~2개를 바꾸게 한다.
- chunk마다 사용자의 실제 상황을 담은 문장을 적어도 하나 만들게 한다.
- 피드백은 의미 전달, chunk 선택, 자연스러움에 집중하고 핵심 수정 1~2개만 준다.

### 5. 상황을 바로 영어로 묘사 (5분)

사용자의 현재 일상에 맞는 상황 3개를 주고 한국어 문장 전체를 번역하게 하지 말고, 상황에서 바로 영어를 말하게 한다. 예: 늦게 일어난 직후, 외출 준비 중, 지하철로 이동 중.

### 6. 마무리 회상 (5분)

- 학습 화면을 보지 않고 오늘의 핵심 이미지를 설명하게 한다.
- 상황 단서만 주고 chunk를 3~5개 회상하게 한다.
- 오답은 즉시 여러 번 재학습하지 말고 다음 노출 대상으로 기록한다.

## 복습과 진도

- 기본 복습 간격은 1, 4, 7, 30일로 하되 정답률과 사용자 피로도에 맞게 조절한다.
- 복습은 설명 재읽기보다 상황→chunk, 문장 빈칸, 새로운 자기 문장 생성으로 진행한다.
- 다른 날에 3회 안정적으로 회상한 항목은 `learning`에서 `familiar`로, 나중 점검에서도 성공하면 `usable`로 바꿀 수 있다.
- 같은 패턴을 2회 이상 틀리거나 이해만 하고 생산하지 못하면 persistent 항목으로 올린다.
- Tier 2로 넘어가기 전에 Tier 1 모두를 완벽히 암기할 필요는 없다. 최근 2주 회상률이 안정적이고 일상 생산 연습이 가능하면 새 항목을 점진적으로 섞는다.

## 기록과 Git

학습 종료 후 세션, 단어, 복습, 진도, 장기 약점 기록을 필요한 범위에서 갱신한다. 사용자의 의도와 달리 자연스러운 문장으로 수정했다면 원문과 수정문을 모두 남긴다.

```bash
cd ~/.fhdufhdu/feel-english
git status --short
git add sessions words reviews progress persistent
git commit -m "Add Feel English study record for YYYY-MM-DD"
git push
```

예상하지 못한 로컬 변경을 보존하고 관련 파일만 스테이징한다. 저장이 막혀도 학습은 채팅에서 계속할 수 있지만, 기록이 저장되지 않는다는 점을 먼저 알린다.
