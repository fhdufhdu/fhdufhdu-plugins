# Mac 파일 정리

로컬 macOS에서 실행한다. `df`, `du`, `find`, `stat`, Finder 등 기본 도구로 조사하고, [후보 선별과 보호 규칙](references/candidates.md)을 적용한다. 후보를 조사할 때는 파일을 수정하지 않는다.

## 조사 범위 정하기

- 저장 공간이 부족하면 `df -k /`로 여유 공간을 확인한다. Mac 전반의 후보를 묻는 경우 사용자 캐시·로그와 로컬 다운로드·바탕화면부터 살펴본다. 프로젝트 산출물은 사용자가 지정한 프로젝트 루트에서만 확인한다.
- 경로가 지정되면 그 위치의 바로 아래부터 확인한다. 필요한 하위 폴더만 더 살펴보고, 시스템 전반 정리로 범위를 넓히지 않는다. 용량 목표가 있으면 다시 만들기 쉬운 후보부터 순위를 매겨 목표에 필요한 범위로 좁힌다.
- 탐색 결과는 파일명, 유형, 할당량, 수정일 등 필요한 메타데이터를 중심으로 작성한다. 중복 확인을 요청한 경우 로컬 일반 파일을 크기로 먼저 묶고, 같은 크기에서만 SHA-256을 비교한 뒤 해시가 같은 파일을 `cmp -s`로 검증한다. 동일 장치·inode를 공유하는 하드 링크는 별도 복사본으로 계산하지 않는다.

## 미리보기 만들기

각 후보의 정확한 경로, 유형, 디스크 할당량, 선정 근거, 복구 또는 재생성 비용을 표에 적는다. 폴더 분류 요청에는 원본과 목적지를 보여 준다. 요청에서 지정한 보호 경로와 그 하위 항목을 제외하고, 후보 폴더 안에 보호 경로가 있는 경우 그 폴더도 통째로 옮기지 않는다.

근거가 충분한 후보, 사용자가 판단해야 할 파일, 누락된 범위를 표시한다. 권한 오류와 중단된 검사는 미측정으로 기록한다. 상위 폴더와 그 안의 항목 및 동일 장치·inode를 중복 합산하지 않는다. `du`의 할당량은 후보 크기 추정치다. APFS 스냅샷, 클론, 하드 링크 때문에 실제 여유 공간 증가는 다를 수 있다.

## 선택한 항목 처리하기

1. 미리보기만 요청한 경우 결과를 전달하고 마친다. 목록이 여러 항목이거나 범위가 포괄적이면 정확한 경로를 제시하고 사용자의 선택을 받는다. 사용자가 이미 정확한 원본과 작업을 지시했다면 그 범위에 적용한다.
2. 실행 직전에 승인된 경로의 포함 범위와 소유권, 심볼릭 링크 여부, 보호 규칙을 다시 확인한다. 미리보기에서 기록한 장치·inode·유형·크기·수정 시각과 달라졌거나 하위 활동을 재검증할 수 없는 항목은 건너뛴다. 새로 발견한 항목은 기존 선택에 포함하지 않는다. 이동 대상에 이름 충돌이 있으면 해당 항목을 건너뛴다.
3. Finder 또는 macOS 휴지통 기능으로 선택한 항목만 처리한다. 폴더 분류에는 덮어쓰기 없는 이동을 사용한다. 휴지통을 비우거나 관리자 권한으로 진행하지 않는다. 파일 이동이나 휴지통 접근이 차단되면 오류 범위를 기록한다.
4. 원본과 이동 목적지 또는 휴지통 처리 결과를 확인한다. 성공·건너뜀·실패 건수와 대표 경로를 보고한다. 휴지통으로 이동한 크기는 처리 규모로 표시한다. 여유 공간 변화가 필요하면 같은 볼륨에서 `df -k`를 다시 확인한다.
